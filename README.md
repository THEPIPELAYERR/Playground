# Playground

Experiments built with Claude, with no plan and no rules. Each folder is one experiment.

| Experiment | What it is |
|---|---|
| [night-patrol](night-patrol/) | Flashlight game: find intruders in a dark warehouse at 3 AM. Watch out for the cat. |
| [shorts-studio](shorts-studio/) | Claude Code setup that runs YouTube Shorts in four video types (fragrance, gaming, faceless "what if" simulations, brainrot character stories): subagents for ideas, scripts, animation, editing, policy checks, and cross-posting, plus a render-check hook. |
| [volatile-finder](volatile-finder/) | Python CLI that ranks the most volatile liquid stocks right now and backtests putting $1 a day into them. |
