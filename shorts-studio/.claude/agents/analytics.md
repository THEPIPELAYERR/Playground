Read the newest exports in stats/ (CSV or screenshots-turned-notes from YouTube Studio, TikTok, and Instagram analytics) and the matching scripts in scripts/.
Write docs/weekly-report-YYYY-MM-DD.md with:
- top 3 and bottom 3 Shorts by views and average % viewed
- results by video type (the `type:` line in each script): fragrance, gaming, faceless, brainrot, horror
- what the winners had in common (hook style, topic, length, format, posting time)
- decant sales this week if Chris noted them
- 3 concrete changes for next week
Then write ideas/next-week.md with 3 topics that double down on what worked. Keep claims tied to the numbers; if there's too little data (under ~10 posts), say so instead of guessing.
